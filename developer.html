Кабінет розробника

Це твій міні-магазин на GitHub Pages. Нові додатки додаються через файл apps.json у репозиторії магазину.

Важливо

З браузера «залити APK як у Google» тут неможливо — немає сервера. Захист GitHub: тільки власник репо (ти) може змінювати файли. Люди з вулиці додати додаток не можуть.

Як додати новий додаток

  1. Збери APK (наприклад через GitHub Actions у своєму репо додатку).
  2. Виклади APK у Releases того репо (файл, наприклад app-debug.apk).
  3. Відкрий репо магазину: Cherkasy-1-2-Download
  4. Відредагуй файл apps.json — додай новий об’єкт у масив apps.
  5. Збережи (Commit). Через 1–2 хв додаток з’явиться в магазині.

Приклад запису в apps.json

{
  "id": "my-app",
  "name": "Назва додатку",
  "shortDescription": "Коротко в один рядок",
  "description": "Повний опис для сторінки додатку.",
  "icon": "📱",
  "category": "Інше",
  "version": "1.0",
  "apkUrl": "https://github.com/USER/REPO/releases/latest/download/app-debug.apk",
  "releasesUrl": "https://github.com/USER/REPO/releases",
  "updated": "2026-10-07"
}

id — латиницею, унікальний.
apkUrl — пряме посилання на файл APK (краще з Releases).

Посилання

  • Магазин: головна
  • Репо магазину: GitHub
  • Редагувати каталог: apps.json

Захист

  • Змінювати магазин може лише акаунт з правами на репо (ти).
  • Не викладай токени GitHub у чати й у код.
  • APK краще тримати в Releases, не в гілках репо.
